# מדריך פריסה מלא - ממערכת ריקה לעמדת קיוסק חיה בספרייה

מדריך זה מניח שהקוד (גם צד השרת ב-`netlify/functions/library-*.js` וגם
KioskApp כאן) כבר נמצא ב-branch שנפרס (deployed) בנטליפיי. הוא מכסה את כל מה
שנשאר: הגדרות שרת, בניית האפליקציה, והתקנה על המחשב הפיזי בספרייה.

---

## שלב 1: משתני סביבה בנטליפיי (Site settings → Environment variables)

| משתנה | ערך | להשגה מ... |
|---|---|---|
| `LIBRARY_STATION_API_KEY` | מחרוזת אקראית ארוכה שאתם בוחרים (למשל `openssl rand -hex 32`) | אתם ממציאים - זה הסוד המשותף בין השרת לעמדה |
| `LIBRARY_NEDARIM_MOSAD` | מספר המוסד בנדרים פלוס (7 ספרות) | נדרים פלוס (יתכן ואותו מוסד כמו בית הכנסת, יתכן חדש - תלוי איך תרצו שהדוחות שם ייראו) |
| `LIBRARY_NEDARIM_API_VALID` | "טקסט אימות" (ApiValid) - **לא** אותו דבר כמו ApiPassword שכבר יש לכם | מסך "מפתחות API" בנדרים פלוס, בתפריט "עוד" |
| `LIBRARY_NEDARIM_CALLBACK_URL` | (אופציונלי) `https://YOUR-SITE.netlify.app/.netlify/functions/library-nedarim-callback` | אם לא מוגדר, הקוד בונה אותו לבד מכתובת הבקשה - מומלץ בכל זאת להגדיר במפורש |

⚠️ **לפני שמישהו באמת ישלם דרך זה**: יש לוודא מול נדרים פלוס (office@nedar.im)
שהשימוש הזה (הקמת עסקה בצד שרת + אייפרם בתוך אפליקציית Windows) מאושר עבור
המוסד שלכם - ראו סעיף 3.5 במסמך האפיון. בלי אישור זה, ה-API עלול פשוט לדחות
את הבקשות.

בדקו גם: אם עדכנתם `netlify.toml` /`package.json` root - אין צורך, כל
ה-functions החדשים כבר בתיקיית `netlify/functions` הקיימת ומשתמשים באותה תלות
(`@netlify/blobs`) שכבר בפרויקט.

## שלב 2: בניית KioskApp

ראו `kiosk-app/README.md` להוראות בנייה מלאות. בקצרה, על מחשב Windows עם .NET 8 SDK:

```powershell
cd kiosk-app/src
dotnet restore
dotnet build          # לתקן שגיאות קומפילציה אם יש - ראו האזהרה ב-README
dotnet test KioskApp.Core.Tests
dotnet publish KioskApp -c Release -r win-x64 --self-contained true
```

זהו לא בהכרח חייב לקרות על מחשב הספרייה עצמו - אפשר לבנות על מחשב פיתוח רגיל
ולהעתיק את תיקיית ה-`publish` למחשב הספרייה (למשל בדיסק-און-קי).

## שלב 3: התקנה על מחשב הספרייה

### 3.1 הכנה

1. העתיקו את תוכן `publish\` לתיקייה `C:\KioskApp` במחשב הספרייה (או השתמשו
   ב-installer שנבנה מ-`kiosk-app/installer/KioskAppInstaller.iss`).
2. ערכו את `C:\KioskApp\appsettings.json` עם כתובת האתר האמיתית ו-`LIBRARY_STATION_API_KEY`
   האמיתי (**אותו ערך בדיוק** כמו בנטליפיי, שלב 1).
3. ודאו ש-[WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
   מותקן (כמעט תמיד כן ב-Windows 10/11 מעודכן).
4. ודאו שיש מדפסת מוגדרת ועובדת ב-Windows (רגיל, לא קשור לקוד).

### 3.2 בדיקה **לפני** נעילת המחשב

חשוב מאוד: הריצו את `KioskApp.exe` ישירות (כפליים-קליק, כמו כל תוכנה) **לפני**
שאתם מריצים את סקריפט הנעילה. בדקו את כל הזרימה:

1. מסך התחברות נטען - נסו להתחבר עם משתמש שיצרתם דרך `admin.html` (טאב
   "קיוסק ספרייה").
2. מסך בחירת תוכנה מציג את "אוצר החכמה" (או כל תוכנה שהגדרתם ב-`admin.html`,
   תחת "הגדרות" → "תוכנות מאושרות" - ודאו שה-`exePath` שם הוא הנתיב האמיתי
   על המחשב הזה).
3. התוכנה נפתחת, וה-Overlay מופיע למעלה עם שם המשתמש, יתרה וטיימר.
4. נסו להדפיס דף - בדקו שהיתרה יורדת בהתאם לתעריף שהגדרתם.
5. נסו "הטענת כסף" עם סכום קטן וכרטיס בדיקה (ראו את סביבת הבדיקות של נדרים
   פלוס בתיעוד ה-API - Mosad=0, טקסט אימות j+iyEFN3bE - **רק לפני שיש לכם
   מוסד/ApiValid אמיתיים משלכם, לצורך בדיקת האינטגרציה בלבד**).
6. נסו "ניתוק" וודאו שחוזרים למסך ההתחברות, ושהתוכנה שהייתה פתוחה נסגרת.
7. סגרו את `KioskApp.exe` (Alt+F4 עדיין עובד בשלב הזה, לפני שהוא Shell).

אל תמשיכו לשלב הבא עד שכל זה עובד. אחרי שהמחשב ננעל, הרבה יותר קשה לתקן דברים.

### 3.3 נעילת המחשב

הריצו PowerShell **כמנהל מערכת** (Run as Administrator):

```powershell
cd C:\KioskApp\setup   # או לאן שהעתקתם את תיקיית setup
.\Setup-KioskUser.ps1
```

הסקריפט:
- יוצר משתמש `kiosk-user` בהרשאות רגילות (לא מנהל)
- מגדיר התחברות אוטומטית אליו בכל אתחול
- קובע את `KioskApp.exe` כ-Shell (במקום Explorer)
- מסתיר Task Manager / נעילת מסך / החלפת משתמש מתפריט Ctrl+Alt+Del
- משבית את מקש Windows
- מבטל AutoRun מהתקני USB

בסוף הריצה הוא ידפיס סיסמה אקראית שנוצרה עבור `kiosk-user` (אלא אם סיפקתם
`-KioskPassword` בעצמכם) - **שמרו אותה במקום בטוח**, תצטרכו אותה אם פעם תרצו
להתחבר לאותו משתמש ידנית לצורך תחזוקה.

**הפעילו את המחשב מחדש.** בהפעלה הבאה, המחשב אמור לעלות ישר למסך ההתחברות של
KioskApp, בלי מסך login של Windows ובלי גישה לשולחן העבודה.

## שלב 4: איך יוצאים ממצב קיוסק אם צריך (חשוב לשמור את זה!)

מתישהו תצטרכו לתחזק את המחשב (עדכוני Windows, שינוי הגדרות, בדיקת תקלה). דרכים
לחזור למצב רגיל:

**דרך מומלצת - מרחוק/ברוגע:** אם יש לכם עדיין חשבון Administrator נפרד (לא
`kiosk-user`) על אותו מחשב, התחברו אליו (למשל ע"י ניתוק כבל הרשת + Safe Mode,
או פשוט: אם `kiosk-user` הוא לא המשתמש היחיד, ב-Safe Mode ניתן בד"כ לבחור
משתמש אחר) והריצו:
```powershell
cd C:\KioskApp\setup
.\Remove-KioskLockdown.ps1
```
ואז הפעילו מחדש - Explorer רגיל יחזור.

**אם ננעלתם לגמרי בחוץ:** אתחלו למצב בטוח (Safe Mode - למשל ע"י כיבוי כפוי
3 פעמים ברצף באמצע עליית Windows, מה שגורם ל-Windows להיכנס אוטומטית ל-
Automatic Repair, ומשם Troubleshoot → Advanced options → Startup Settings →
Safe Mode). ב-Safe Mode ה-Shell המותאם אישית **לא** נטען (Windows מתעלם ממנו
במצב בטוח), כך שתוכלו להתחבר עם `kiosk-user` (עם הסיסמה שנשמרה בשלב 3.3)
ולהריץ את `Remove-KioskLockdown.ps1` משם - אבל שימו לב ש-`kiosk-user` אינו
מנהל מערכת, אז ייתכן שתצטרכו קודם להריץ PowerShell כ-Administrator דרך
"Run as different user" עם חשבון Administrator מובנה של Windows.

**מומלץ מראש:** לפני ההתקנה הראשונה בפועל, ודאו שיש לכם לפחות חשבון
Administrator אחד ידוע (הסיסמה שלו שמורה) על המחשב, שאינו `kiosk-user` -
זו רשת הביטחון הכי פשוטה.

## שלב 5: בדיקה מסודרת אחרי הנעילה

1. הפעילו את המחשב - אמור לעלות ישר למסך ההתחברות של הקיוסק.
2. נסו Ctrl+Alt+Del - Task Manager/נעילה/החלפת משתמש אמורים להיות מוסתרים.
3. נסו מקש Windows - לא אמור לעשות כלום.
4. חזרו על כל הבדיקות משלב 3.2 (התחברות, בחירת תוכנה, הדפסה, הטענת כסף, ניתוק).
5. בדקו את פאנל הניהול (`admin.html` → "קיוסק ספרייה") מדפדפן רגיל - ודאו
   שרואים שם את היתרה/ההיסטוריה מתעדכנות בהתאם למה שקרה בעמדה.

## תחזוקה שוטפת

- **עדכון גרסה של KioskApp**: `dotnet publish` מחדש, העתקת הקבצים החדשים
  מעל הישנים ב-`C:\KioskApp` (או installer מעודכן) - **לא** לדרוס את
  `appsettings.json` המקומי. הפעלה מחדש.
- **הוספת/הסרת תוכנות מאושרות, שינוי תעריף הדפסה**: דרך `admin.html`, בלי
  צורך לגעת במחשב הספרייה בכלל (העמדה קוראת את ההגדרות מהשרת בכל הפעלה).
- **בעיה בתשלומים**: בדקו קודם את `library-nedarim-callback.js` בלוגים של
  נטליפיי (Netlify → Functions → Logs) - שם יופיעו כשלים באימות/עיבוד.
