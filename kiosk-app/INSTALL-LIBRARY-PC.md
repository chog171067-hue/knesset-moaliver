# התקנת הקיוסק במחשב הספרייה - מדריך מלא

## העיקרון: מה עובר ומה לא

**כל הנתונים נמצאים באתר, לא במחשב:** משתמשים, יתרות, היסטוריה, תעריפים, רשימת
התוכנות המאושרות, הגדרות פתיחת חשבון, שחזור סיסמה בטלפון ותשלומים מנדרים פלוס.
לכן אין מה "להעביר" מהמחשב הישן - המחשב החדש מתחבר לאותו אתר ורואה הכול.

**מה כן צריך במחשב החדש:**
1. תוכנת הקיוסק עצמה (נבנית מהקוד ב-GitHub, בפקודת העדכון הרגילה).
2. קובץ אחד עם הגדרות החיבור לאתר: `appsettings.json` (מעתיקים ממחשב הניסוי).
3. סקריפט הנעילה (פקודה אחת - הוא עושה את כל הגדרות Windows שעשינו בדרך).
4. כמה הגדרות ידניות שסקריפט לא יכול לעשות: BIOS, מדפסת, התוכנות המאושרות, נטפרי.

---

## שלב 0: לפני שמתחילים - ממחשב הניסוי

1. **להעתיק לדיסק-און-קי את הקובץ** `C:\KioskApp\appsettings.json` ממחשב הניסוי.
   יש בו את כתובת האתר ואת "מפתח העמדה" (סוד) - לשמור את הדיסק-און-קי במקום בטוח.
2. **מחשב הניסוי לא נמחק** - אפשר להשאיר אותו כגיבוי. אם לא צריך אותו כעמדה:
   `Remove-KioskLockdown.ps1` מבטל את הנעילה (ראו בסוף).

## שלב 1: הגדרות BIOS (במחשב הספרייה) - ידני

נכנסים ל-BIOS: מדליקים ולוחצים מיד **F2** (ב-Dell) או **Del**.

| הגדרה | ערך | למה |
|---|---|---|
| סדר אתחול (Boot Sequence) | **הדיסק הקשיח / Windows Boot Manager ראשון** | שלא ינסה לעלות מדיסק-און-קי או מהרשת ("Active partition not found" / "PXE") |
| אתחול מהרשת (Onboard NIC / PXE) | **Enabled** בלי PXE, או **Disabled** לאתחול | אותה סיבה |
| אתחול מ-USB | מוריד ברשימה או **Disabled** | דיסק-און-קי ששכחו לא יעצור את העמדה |
| הדלקה אחרי הפסקת חשמל (AC Recovery / Power On after power loss) | **Power On** | אחרי הפסקת חשמל העמדה עולה לבד |
| סיסמת BIOS (Admin/Setup Password) | סיסמה שהצוות יודע | שמשתמשים לא ישנו את כל זה |

שומרים ויוצאים (**F10**).

## שלב 2: Windows - ידני

1. **חשבון מנהל עם סיסמה ידועה.** חובה. אחרי הנעילה, זה הדרך היחידה לתחזוקה.
   עדיף חשבון מקומי (לא חשבון Microsoft). לרשום את הסיסמה במקום בטוח.
2. **עדכוני Windows:** להריץ עדכונים עד הסוף לפני ההתקנה. אחר כך: הגדרות ← Windows Update ←
   אפשרויות מתקדמות ← **שעות פעילות** - לכסות את שעות הפעילות של הספרייה, כדי שהמחשב לא
   יופעל מחדש באמצע.
3. **Smart App Control** (רק ב-Windows 11): אבטחת Windows ← בקרת אפליקציות ודפדפן ←
   אם מופעל - לכבות. הוא חוסם תוכנות לא חתומות, כמו הקיוסק.

## שלב 3: התוכנות המאושרות - ידני

1. להתקין את כל התוכנות שיופיעו בקיוסק (אוצריא וכו').
2. **אוצריא - להתקין ב-`C:\אוצריא`** (כמו במחשב הניסוי). התיקייה הזו מוגנת אוטומטית בסקריפט
   הנעילה (קריאה בלבד). תוכנה שמותקנת ב-`C:\Program Files` מוגנת ממילא ע"י Windows.
   תוכנה שמותקנת בתיקייה אחרת ישירות ב-C - לספר, כדי להוסיף אותה להגנה.
3. **אוצריא - נעילת הקיוסק שלה:** להפעיל בהגדרות של אוצריא את מצב הקיוסק עם סיסמה (כמו
   במחשב הניסוי).
4. **בדף הניהול** (קיוסק ספרייה ← הגדרות ← תוכנות מאושרות): לוודא שהנתיב של כל תוכנה
   הוא הנתיב **במחשב הזה**. אם הוא שונה ממחשב הניסוי - לתקן.

## שלב 4: מדפסת - ידני

1. לחבר את המדפסת, להתקין את הדרייבר שלה, ולהגדיר אותה כ**מדפסת ברירת המחדל**.
2. להדפיס דף ניסיון מ-Windows.
3. לוודא שקיימת המדפסת **Microsoft Print to PDF** (קיימת כברירת מחדל) - עורך הטקסט שומר
   PDF דרכה.

## שלב 5: נטפרי - ידני

אם המחשב מסונן בנטפרי, לבקש פתיחה של הכתובות האלה (אחרת הקיוסק, התשלום או העדכון לא יעבדו):

| כתובת | למה |
|---|---|
| `moaliver.org.il` | האתר - כל פעולה בקיוסק |
| `matara.pro`, `www.matara.pro`, `nedar.im` | תשלומים בנדרים פלוס |
| `github.com`, `codeload.github.com` | הורדת הקוד בעדכון |
| `api.nuget.org`, `www.nuget.org`, `globalcdn.nuget.org` | בניית הקיוסק בעדכון |
| `dotnet.microsoft.com`, `builds.dotnet.microsoft.com` | התקנת .NET (פעם אחת) |

אם משהו בדף של נדרים פלוס לא נטען (למשל אימות "אני לא רובוט") - כנראה עוד כתובת שחסומה
בנטפרי; ביומן הקיוסק (`C:\KioskApp\kiosk-app.log`) רשומות כתובות שנחסמו בחלון של נדרים.

## שלב 6: כלים להתקנה - פעם אחת

1. **Git for Windows:** https://git-scm.com/download/win - התקנה עם ברירות המחדל.
2. **.NET 8 SDK** (לא רק Runtime): https://dotnet.microsoft.com/download/dotnet/8.0 ←
   SDK ← Windows x64.
3. **WebView2 Runtime** - כמעט תמיד מותקן כבר ב-Windows 10/11. אם לא:
   https://developer.microsoft.com/microsoft-edge/webview2/
4. סוגרים ופותחים מחדש את PowerShell, ובודקים:
   ```
   git --version
   dotnet --version
   ```
   (מספר גרסה של dotnet שמתחיל ב-8.)

## שלב 7: הורדת הקוד והתקנת הקיוסק

ב-PowerShell **כמנהל**:

```
git clone https://github.com/chog171067-hue/knesset-moaliver.git C:\KioskSource
```

```
powershell -ExecutionPolicy Bypass -File C:\KioskSource\kiosk-app\setup\Update-Kiosk.ps1
```

בסוף תופיע אזהרה צהובה שאין `appsettings.json` - זה צפוי בהתקנה ראשונה. מעתיקים את הקובץ
מהדיסק-און-קי (שלב 0) לתיקייה `C:\KioskApp`.

## שלב 8: בדיקה לפני הנעילה

מפעילים את `C:\KioskApp\KioskApp.exe` (לחיצה כפולה) ובודקים:
1. מסך הפתיחה עם שני הריבועים.
2. כניסה לחשבון קיים.
3. פתיחת כל תוכנה מאושרת.
4. הדפסת דף אחד - היתרה יורדת.
5. עורך הטקסט: שמירה לדיסק-און-קי.
6. ניתוק.

יוצאים מהקיוסק ב-**Alt+F4** (עובד רק לפני הנעילה). לא ממשיכים עד שהכול עובד.

## שלב 9: נעילה

ב-PowerShell **כמנהל**, מחשבון המנהל (לא מחשבון הקיוסק):

```
powershell -ExecutionPolicy Bypass -File C:\KioskSource\kiosk-app\setup\Setup-KioskUser.ps1
```

הסקריפט שואל אם הסיסמה של חשבון המנהל ידועה - עונים `YES` (באותיות גדולות).

**הסקריפט עושה לבד את כל ההגדרות שעשינו בדרך** (רק למשתמש הקיוסק; המנהל נשאר עם Windows רגיל):
- משתמש `kiosk-user` רגיל (לא מנהל) עם התחברות אוטומטית בכל הדלקה, והקיוסק במקום שולחן העבודה.
- Ctrl+Alt+Delete בלי מנהל משימות, נעילה, שינוי סיסמה, יציאה, **ובלי כפתור הכיבוי/הפעלה**.
- בלי "החלפת משתמש", בלי חלון "הפעלה" (Win+R), בלי הפעלה אוטומטית מ-USB.
- חלונות הקבצים בתוכנות: הכוננים הפנימיים מוסתרים וחסומים, בלי לחיצה ימנית; שמירה רק לדיסק-און-קי.
- הרשאות: `C:\KioskApp`, `C:\KioskSource`, `C:\אוצריא` - קריאה בלבד; בלי כתיבה בכוננים
  פנימיים נוספים וב-`C:\Users\Public`.
- המחשב לא נרדם ולא מכבה מסך; אחרי הפסקת חשמל עולה כרגיל (בלי מסך "תיקון אוטומטי").
- שמירה על ההתחברות האוטומטית גם אחרי כניסת מנהל.
- כפתור "🔧 יציאה למחשב" לחשבונות מורשים (חזרה אוטומטית לקיוסק אחרי 5 דקות בלי כניסה).
- קיצור "חזרה לקיוסק" על שולחן העבודה של המנהל.

מפעילים מחדש את המחשב - הוא אמור לעלות ישר לקיוסק.

## שלב 10: בדיקה אחרי הנעילה

1. המחשב עולה ישר לקיוסק.
2. Ctrl+Alt+Delete - אין מנהל משימות, אין יציאה, אין כיבוי.
3. מקש Windows - לא עושה כלום.
4. חוזרים על הבדיקות משלב 8, ובנוסף: הטענת כסף, "תשלום בכרטיס שמור", "שכחתי סיסמה".
5. **"🔧 יציאה למחשב"** (מחשבון מורשה) ← מסך הכניסה של Windows ← כניסה כמנהל ←
   "חזרה לקיוסק".

## תחזוקה

- **עדכון:** "🔧 יציאה למחשב" ← מנהל ← PowerShell כמנהל:
  ```
  powershell -ExecutionPolicy Bypass -File C:\KioskSource\kiosk-app\setup\Update-Kiosk.ps1
  ```
  ← "חזרה לקיוסק". (לפני כן להוציא דיסק-און-קי.)
- **כניסת מנהל בלי חשבון קיוסק:** כפתור ההדלקה הפיזי (כיבוי) ← הדלקה עם **Shift** לחוץ עד
  שמופיע מסך הכניסה.
- **ביטול הנעילה לגמרי:**
  ```
  powershell -ExecutionPolicy Bypass -File C:\KioskSource\kiosk-app\setup\Remove-KioskLockdown.ps1
  ```
