# טעינת יתרה מנדרים פלוס (Webhook)

כל תשלום במוסד בנדרים פלוס בקטגוריה **"עמדת מחשב"** נטען אוטומטית ליתרה בקיוסק:

- **תשלום בכרטיס שמור** - הכפתור "תשלום בכרטיס שמור" בחלון התשלום בעמדה פותח את הדף הרגיל
  של נדרים פלוס, המשתמש נכנס לאזור האישי שלו בנדרים ומשלם. הסכום נטען לחשבון שביקש את
  התשלום (גם בפתיחת חשבון).
- **תרומה בעמדת נדרים פלוס** בקטגוריה "עמדת מחשב" - נטענת לחשבון לפי תעודת הזהות (ואם אין
  ת"ז בעסקה - לפי הטלפון, רק כשיש חשבון אחד בדיוק עם הטלפון הזה).
- **הוראת קבע** בקטגוריה "עמדת מחשב" - כל חיוב חודשי נטען, כמו מנוי.
- **אין חשבון מתאים** - התשלום נשמר כ"ממתין": נטען לבד כשנפתח חשבון עם אותה ת"ז, ומוצג בדף
  הניהול ← קיוסק ספרייה ← "תשלומים ממתינים" לשיוך ידני.

הטענות מטופס האשראי בעמדה ובאזור האישי באתר ממשיכות לעבוד כמו קודם (עם CallBack משלהן);
ה-Webhook מדלג עליהן כדי שלא ייטענו פעמיים. תשלומים בקטגוריות אחרות (תרומות לבית הכנסת) -
לא נוגעים בהם.

## הגדרה (פעם אחת)

### 1. בדיקה: האם כבר מוגדר Webhook במוסד
בנדרים פלוס: **הגדרות ← API ← Webhook**. אם בשדה **"עדכוני עסקאות"** כבר יש כתובת של מערכת
אחרת - לעצור ולבדוק לפני שמחליפים (לכל מוסד יש כתובת אחת לעדכוני עסקאות).

### 2. מפתח חתימה
1. באותו מסך ← **"חתימת HMAC"** ← הגרלת מפתח. **להעתיק את המפתח** (הוא מוצג פעם אחת בלבד).
2. בנטליפיי: **Site configuration ← Environment variables ← Add a variable**:
   - Key: `NEDARIM_WEBHOOK_SECRET`
   - Value: המפתח שהועתק
3. בנטליפיי: **Deploys ← Trigger deploy ← Deploy site** (כדי שהמפתח ייכנס לתוקף).
4. חזרה לנדרים פלוס ← **"הפעלה"** של חתימת ה-HMAC.

### 3. כתובת ה-Webhook
בנדרים פלוס, בשדה **"עדכוני עסקאות"**:

```
https://<כתובת האתר>/.netlify/functions/nedarim-webhook
```

ושמירה. (כתובת האתר - כמו בהגדרת `ApiBaseUrl` של הקיוסק.)

### 4. בדיקה
- תשלום ניסיון קטן בכרטיס שמור מהעמדה, או תרומה בעמדת נדרים פלוס בקטגוריה "עמדת מחשב".
- היתרה בעמדה / בדף הניהול צריכה להתעדכן תוך שניות.
- אם לא: נטליפיי ← Logs ← Functions ← `nedarim-webhook` - שם רשום מה קרה לכל עסקה
  (למשל "חתימה לא תואמת").

## אבטחה
- כל הודעה נבדקת בחתימת ה-HMAC של נדרים פלוס; הודעה בלי חתימה תקינה לא טוענת כלום. (עד
  שמוגדר מפתח - נבדקת כתובת ה-IP של נדרים פלוס בלבד.)
- כל עסקה נטענת פעם אחת בלבד, לפי מזהה העסקה בנדרים פלוס.
- עסקה בלי מספר אישור, במטבע זר או בסכום לא תקין - לא נטענת; מוצגת ב"תשלומים ממתינים".
- חלון נדרים פלוס בעמדה מוחק את ההתחברות לאזור האישי בכל סגירה, והקיוסק מוחק את כל נתוני
  הדפדפן בכל ניתוק - כדי שהמשתמש הבא לא יוכל לשלם בכרטיס השמור של הקודם.
